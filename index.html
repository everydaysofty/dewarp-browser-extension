Dewarp Chrome Extension Privacy Policy Last updated: September 29, 2026 This Privacy Policy explains how the Dewarp Chrome Extension ("Dewarp Extension", "Extension", "we", "us", or "our") handles information when you use the Extension. The Dewarp Extension is a companion to the Dewarp desktop application. Its purpose is to connect your Chrome browser with the Dewarp desktop application so Dewarp can save and restore browser tabs and windows as part of your workspaces. 1. Information the Extension accesses Browser tab information The Extension reads information about your open browser tabs, including: Tab URLs Tab titles Tab favicons Tab identifiers required to associate tabs with browser windows This information is used to create a browser workspace snapshot that can be saved and restored by Dewarp. Browser window information The Extension reads information about your open Chrome windows and the tabs associated with each window. This allows Dewarp to preserve the organization of your browser windows when restoring a workspace. Extension settings The Extension stores a small amount of information locally using Chrome's storage API, including: A randomly generated browser-profile identifier The timestamp of the last successful workspace snapshot 2. How the information is used Information accessed by the Extension is used solely to provide Dewarp's workspace-saving and restoration functionality. Specifically, the information is used to: Create a snapshot of your open Chrome tabs and windows Send the snapshot to the Dewarp desktop application Allow Dewarp to save browser information as part of a workspace Allow Dewarp to restore the browser workspace later Display connection and synchronization status in the Extension popup Distinguish browser profiles when communicating with the Dewarp desktop application The Extension does not use browser information for advertising, profiling, creditworthiness decisions, or unrelated purposes. 3. Where your information is sent The Dewarp Extension communicates with the Dewarp desktop application running on your computer through a local service on the loopback address: 127.0.0.1:41234 The Extension is designed to send browser workspace information to this local Dewarp application. The Extension does not require a remote server to receive your browser tab information. 4. Information we do not collect The Dewarp Extension does not intentionally collect: Passwords Authentication credentials Credit card or payment information Health information GPS or precise location information Emails or private messages Keystrokes Mouse movements Webpage content Text, images, videos, audio, or other content displayed inside webpages The Extension does not inject scripts into webpages for the purpose of reading webpage content. 5. Data sharing We do not sell your data. We do not transfer your browser tab information to advertisers, data brokers, or other third parties. Browser workspace information accessed by the Extension is transferred to the Dewarp desktop application running locally on your computer for the purpose of providing Dewarp's workspace-saving and restoration functionality. 6. Data storage The Extension stores limited configuration information using Chrome's local extension storage. This includes the randomly generated browser-profile identifier and the timestamp of the last successful snapshot. Dewarp may store workspace information locally according to the Dewarp desktop application's own data-storage behavior. 7. Data security Dewarp is designed to keep browser workspace communication local to the user's computer. The Chrome Extension communicates with the Dewarp desktop application through a local loopback service. The Extension does not intentionally transmit browser workspace information to a remote server. 8. User control You can disable or uninstall the Dewarp Chrome Extension at any time through Chrome's extension settings. Uninstalling the Extension prevents it from continuing to access Chrome tab and window information. 9. Children's privacy Dewarp is not specifically directed toward children under the age of 13. We do not knowingly collect personal information from children through the Dewarp Chrome Extension. 10. Changes to this Privacy Policy We may update this Privacy Policy when the Extension's functionality, data practices, or legal requirements change. When changes are made, we will update the "Last updated" date at the top of this Privacy Policy. 11.
